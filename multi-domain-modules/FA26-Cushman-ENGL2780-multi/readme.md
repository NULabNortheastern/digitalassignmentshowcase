## Summary of Module
This module will cover creating a chronological narrative with TimelineJS, designing infographics on Canva, and developing a StoryMap. It covers best practices and questions to consider before creating your Timeline, infographic, or StoryMap and demonstrates steps for using each tool. 

## Learning Goals
- Understand how to collect data for mapping or creating a timeline
- Understand the design process of creating data visualizations
- Understand KnightLab TimelineJS's, Canva, and KnightLab StoryMap's interfaces

## Learning Objectives
- Articulate particular choices made when telling a story using a timeline, infographic, or map
- Follow a step-by-step guide for creating, saving, and publishing maps or timelines using KnightLab StoryMap and TimelineJS tools
- Implement data into KnightLab StoryMap and TimelineJs templates, including location information, images, and text
